# Lachezar Todorov Resume Website

Статичен личен сайт (HTML/CSS/JS), готов за публикуване в GitHub Pages.

## Какво включва

- Лична информация и образование
- Професионален опит
- Постижения със снимки
- Проекти със снимки + GitHub/demo линкове
- Сертификати със снимки + линкове за валидация
- Бутон за сваляне на CV (`download`)

## Как да го попълниш

1. Редактирай данните в `index.html`.
2. Замени снимките в:
   - `assets/images/`
   - `assets/certificates/`
3. Добави CV файла като:
   - `cv/Lachezar-Todorov-CV.pdf`

## Пускане локално

Отвори `index.html` в браузър.

## Deploy в GitHub Pages

1. Качи проекта в GitHub repo.
2. Влез в **Settings > Pages**.
3. Под **Build and deployment** избери:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / root
4. Изчакай GitHub да публикува сайта и отвори дадения URL.
